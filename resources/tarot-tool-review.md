# Tarot Tool Review — AI Tarot Comparison Design

[Open the interactive Claude Artifact](https://claude.ai/code/artifact/1be108b4-1a73-4202-a7bd-a2ff8499667c)

Tarot Tool Review is an interactive buyer's-guide and comparison-page design concept for evaluating online and AI-assisted tarot reading tools. The prototype presents a practical framework that readers can use before sharing a personal question with a tarot application.

## Evaluation framework

The design compares tools using six criteria:

1. Card-name and interpretation accuracy
2. Spread-position and reversal handling
3. Consistency across repeated readings
4. Privacy, storage, and retention clarity
5. Reading-history and journaling support
6. How the tool responds when an interpretation does not fit

It also contrasts four common product types: free web spreads, app-store tarot apps, general AI chatbots, and dedicated AI reading sites. Deckaura appears as the dedicated-site review example.
